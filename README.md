# NapCat-Docker 宝塔面板一键部署模板

基于 [NapCat-Docker](https://github.com/NapNeko/NapCat-Docker) 的宝塔面板（Docker 应用商店）一键部署模板。

## 什么是 NapCat

NapCat 是一款基于 NTQQ 协议的现代化 QQ Bot 框架，支持 WebSocket / HTTP 等多种通信方式，可搭配 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 等机器人框架使用。

## 通过宝塔面板使用

1. 在宝塔面板 **Docker → 应用商店** 中的分类 **外部应用** 的右上角点击导入应用
2. 填写仓库地址 `https://github.com/makotowu/NapCat-Docker.Baota.git` ，点击导入
3. 选择 NapCat 应用，点击安装
4. 填写配置，等待安装即可
